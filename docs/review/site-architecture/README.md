# Architecture page review

Source baseline: `251f3ea2` (`origin/main`, fetched before editing). The change adds `site/pages/architecture.html`, keeps the Pond palette and standard-library builder, and links the page from the shared navigation/footer, the homepage’s How it works section, the guides index and the Notes guide. No image assets or network dependencies are added to the deployed site.

The navigation keeps Architecture visible on phones. At phone widths Guides remains available in the footer; below 380 pixels the decorative brand glyph is hidden to fit the header. The feature matrix is a labeled, keyboard-focusable horizontal scroll region; symbols have screen-reader text. The diagram uses semantic HTML with live text, shared theme colors and a caption.
