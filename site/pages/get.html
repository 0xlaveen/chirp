Chirp is private dictation and live meeting notes, powered by your own computer — a Mac, a Windows PC or a Linux box. There isn’t a download yet. Packaged apps for macOS, Linux and Windows are on the way, along with an Android APK and an iOS app. Until they land, everything is self-serve: you build Chirp from source, on the machine you already own.

The easiest route is to point a coding agent at the repository and work through it together. Prefer to do it yourself? The guides take it one step at a time.

Why build it yourself for now?

Packaging takes signing, notarizing, store review and support across OS versions. Instead of rushing a half-finished installer, the source is public and usable today. No waiting list, no account, no telemetry.

Two ways to start

01 / Recommended today

Point a coding agent at the repo

If you already use a coding agent in Terminal, this is the least fiddly path. Paste the prompt below and answer its questions. The agent clones the repository, runs the installer, and stops for the parts only you can do.

Help me install Chirp on this Mac from source:
https://github.com/araa47/chirp

Read README.md and mac/README.md, then run ./scripts/install-mac.sh
from the repository root and explain each step as you go.

Ask before installing anything, changing system settings, approving the
signing identity or granting permissions. Stop for the steps only I can
do — signing, choosing models, and pairing a phone. Never print or share
the pairing token, QR code or link. Never enable Tailscale Funnel or
expose the server beyond 127.0.0.1 or my tailnet.

02 / By hand

Follow the guides yourself

No agent needed. Start with the computer that will run the Chirp server (a Mac, Windows PC or Linux box): it runs the speech model every other device uses. Each guide says what you need, what to type, and what to click.

  1. Set up the Mac appAbout 15 minutes, mostly downloads.
  2. Add a Windows PCServer, service and desktop app. Early.
  3. Add a Linux boxServer, systemd service and desktop app. Early.
  4. Add an Android phoneBuild the APK, pair with a QR code.
  5. Add an iPhone or iPadXcode, signing and the keyboard.
  6. Take notesTurn a meeting into Markdown.

What you need

  • A machine to run the server, on and reachable whenever you dictate: a Mac on macOS 14 or later (Apple Silicon uses MLX, fastest; Intel uses ONNX Parakeet), a PC on Windows 10 or 11, or a Linux desktop (X11 or Wayland). The desktop apps are the native Mac app (most polished) and the shared Windows/Linux app (early).
  • About 15 minutes for the first computer. Add other devices when you’re ready; each takes a little longer.
  • Tailscale on the server machine and phone, if you want to dictate from a phone.
  • Full Xcode for iPhone or iPad; the Command Line Tools are enough for the Mac. Windows and Linux need Rust and Node 22+ for the desktop app.
  • Comfort with Terminal — or an agent. You don’t need to write code. You do need to run a few commands.

Without a GPU — Intel Macs and most Windows/Linux machines — built-in clean-up and Notes structuring run on CPU and can be slow. Dictation works without them. Turn clean-up off, or use an OpenAI-compatible local endpoint such as Ollama or LM Studio. Notes can keep a plain transcript with Structure notes off.

Questions

Is there a download?

Not yet. Packaged apps for macOS, Linux, Windows, Android and iOS are coming soon. Today Chirp is self-serve: everything is built from the source in the repository. The coding agent guide is the quickest route.

When will the packaged apps be out?

Soon, but there’s no date to give you yet. Signing, notarizing and store review take time. When a packaged build is ready it will appear in the changelog and the repository first.

Do I need to know how to code?

No. You need to run commands in Terminal, or let a coding agent run them with you. The guides spell out every command, and the agent prompts tell the agent to ask before it changes anything.

What does “point an agent at the repo” mean?

Open the coding agent you already use — Claude Code, Codex, Cursor, or another agent that can run shell commands on your Mac — and paste the prompt from the agent guide. The agent reads the READMEs, runs the build, and stops for the decisions that need you.

Can I use Chirp on Windows or Linux today?

Yes — early, and from source. The speech server and a desktop app run on Windows 10/11 and Linux (X11, or Wayland through your desktop’s Global Shortcuts portal). Windows is verified in CI, with a manual acceptance pass on real PCs still pending. See the Windows guide and the Linux guide. Packaged downloads are coming later.

Is Chirp really free?

Yes. There’s no subscription, usage fee or Chirp account. You supply the computer, electricity, and any network or developer services you choose. The source is public; the Android keyboard incorporates GPL-3.0 HeliBoard.
