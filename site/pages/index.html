How it works

One computer.
Every device.

Chirp turns your Mac, PC or Linux box into a private speech server. Your phone sends audio over your own Tailscale network and gets text back. Nothing goes to a Chirp cloud.

Chirp is for people willing to run their own speech server — a Mac, a Windows PC or a Linux box. Other tools offer easier installation, more mature meeting workflows or a phone that works on its own.

The short version: Chirp’s difference is the computer you already own — it runs the speech engine for every device, without a vendor speech service. The trade-off is real: you build it, run it and keep that machine reachable. Windows and Linux support is new and early. If you need a packaged download today, or a phone that works without your server, one of the other tools is the better fit.

  • You own a Mac (macOS 14+, Apple Silicon or Intel), a Windows 10/11 PC or a Linux desktop you can leave on.
  • You want local clean-up and meeting notes, shared by your desktop and phone.

Consider another tool if…

  • You need a packaged, one-click download today.

A few practical questions

Before you install.

See what’s new ↗
Can I download Chirp as an app yet?

Not yet. Packaged apps for macOS, Linux, Windows, Android and iOS are coming soon. Today Chirp is self-serve: everything is built from source. See Get Chirp, or start with a coding agent.

Which Mac do I need?

Any Mac running macOS 14 or later: Apple Silicon uses MLX (fastest), and Intel uses ONNX Parakeet. The Mac runs the speech server and must be on and reachable for phone dictation. Download the speech model once. On Intel Macs, built-in clean-up and Notes structuring run on CPU and can be slow. Dictation works without them: turn clean-up off, or use an OpenAI-compatible local endpoint such as Ollama or LM Studio. Notes can keep a plain transcript with Structure notes off.

Is there a Windows or Linux app?

Yes — early, and from source. The speech server and a desktop app (tray icon, hold-to-talk key, live HUD, typed or pasted text, and a local Notes library) run on Windows 10/11 and Linux. Windows is verified in CI, including a real transcription smoke test, but a manual acceptance pass on real PCs is still pending. On Linux, X11 has single-key hold shortcuts; on Wayland, shortcuts go through your desktop’s Global Shortcuts portal and depend on it. Clean-up on a CPU, without a GPU, is slow — dictation works without it. See the Windows guide and the Linux guide; packaged downloads are coming later.

Does it work offline?

Desktop dictation can run without internet after the models are downloaded. Phones need a working Tailscale connection to your server machine; don’t assume phone dictation works without connectivity. Chirp doesn’t run the speech model on the phone.

What about battery?

The server machine does the recognition work, while the phone records and sends audio. That still uses battery, especially during long notes or an armed iOS keyboard session. Real-device battery cost hasn’t been established; there’s no battery-life claim.

Where do audio and notes go?

Audio streams to your own server machine for recognition. Notes stay on the device that recorded them. Keeping audio for replay is optional and local; it’s off by default (desktop Notes keep text only, never audio). Dictation history is also opt-in. No Chirp cloud, telemetry or Chirp account.

Why does iOS show the microphone indicator?

iOS won’t let a keyboard use the microphone. Chirp’s app holds a timed session ready and passes text to its keyboard. The orange indicator stays on while that session is armed; tap End to release it. Between dictations, audio is discarded.

Which phones can use it?

Android 12 or later, and iPhone or iPad on iOS/iPadOS 18 or later, with Tailscale and a reachable Chirp server — a Mac on macOS 14+, or early, a Windows 10/11 PC or Linux box. Android uses a self-built arm64 APK today; a packaged APK is coming soon. iOS requires your own Xcode signing; it’s early, with an iPad install verified and iPhone hardware testing pending.

Is it really free?

Chirp has no subscription or usage fee. You supply the server machine, electricity and any developer-account or network services you choose. The source is public; the Android keyboard incorporates GPL-3.0 HeliBoard. See the repository and component licenses.
