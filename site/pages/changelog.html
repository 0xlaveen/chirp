October 27, 2026

Speaker labels are on by default, with Saved voices on every device

Label speakers is now on by default on the Mac, Android and iPhone/iPad, and the speaker model downloads by itself the first time, with a status line and a Turn off, instead of asking first. Naming a person can remember their voice in one Saved voices library on your Chirp server, shared by every device that uses it: name someone on your phone and your Mac recognizes them too. A Name speakers sheet appears after Stop on all three. Android and iOS ask your computer to compare voices; the Mac still labels on the Mac itself.

#248 · iOS labels on by default · #250 · Mac · #253 · Android · #252 · Server saved-voice library · #268 · iOS Saved voices

iPhone and iPad: a keyboard top row and a hardware-keyboard shortcut

Chirp Keyboard’s top row now matches Android’s: word suggestions in the middle, options and the mic at the edges, and the same height in every state. On iPad, hold Right ⌥ Option inside Chirp to dictate. Elsewhere iPadOS only allows a toggle: make a Shortcuts key with Full Keyboard Access to start and stop.

#267 · Keyboard top row · #266 · Hardware-keyboard shortcut

“Your computer”, not “your Mac”

The Android and iOS apps now say “your computer” where they used to say “your Mac”, since your Chirp server can be a Mac, a Windows PC or a Linux box.

#264 · Android · #269 · iOS

October 26, 2026

Chirp comes to Windows and Linux

The speech server now runs on Windows 10/11 and Linux, with a background service on each (a per-user Task Scheduler task on Windows, a systemd user unit on Linux), ONNX Parakeet on the CPU with opt-in CUDA/DirectML, and a shared Tauri desktop app: tray icon, hold-to-talk key, live HUD, typed or pasted insertion and a local Notes library with owner-only file permissions. On Linux, X11 gets single-key holds and Wayland uses the desktop’s Global Shortcuts portal. It’s early: Windows is verified in CI, with a manual acceptance pass on real PCs still pending, and CPU clean-up without a GPU is slow.
