October 26, 2026

Chirp comes to Windows and Linux

The speech server now runs on Windows 10/11 and Linux, with a background service on each (a per-user Task Scheduler task on Windows, a systemd user unit on Linux), ONNX Parakeet on the CPU with opt-in CUDA/DirectML, and a shared Tauri desktop app: tray icon, hold-to-talk key, live HUD, typed or pasted insertion and a local Notes library with owner-only file permissions. On Linux, X11 gets single-key holds and Wayland uses the desktop’s Global Shortcuts portal. It’s early: Windows is verified in CI, with a manual acceptance pass on real PCs still pending, and CPU clean-up without a GPU is slow.

October 25, 2026

A more consistent iOS dark appearance

Dark tonal fills now follow the raised Pond surfaces. Setup can be reopened from its reminder card, and new large-type and Reduce Motion captures document those states.

#209 · iOS Pond refinements

iPhone and iPad get their Pond shell

A dedicated Dictate screen, iPad sidebar and guided onboarding for pairing, microphone access and the keyboard. The shared foundation brings Pond colors, the Ripple and the Chirp glyph to iOS. Personal install through Xcode; early hardware validation.

Speaker labels in Live Notes, on Android and Mac

Opt in to distinguish speakers in your transcript, with consent and model setup before use. Android labels through the server; Mac labels on the Mac itself and adds controls to rename, merge or separate people.
