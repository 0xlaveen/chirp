Set up Chirp on Windows

Install the speech server, run it as a background task at logon, build the desktop app, then hold a key and talk into any program. About 30 minutes, most of it downloads. This is new, early software — read the note below before you start.

Before you start

Chirp on Windows 10/11 runs the same speech engine as the Mac: Parakeet TDT v2 through ONNX Runtime, int8 on the CPU by default, with CUDA and DirectML as opt-in accelerators. Speech recognition stays on this PC; the server listens on 127.0.0.1:7821 only.

Windows support is early — here's exactly what that means.

Everything builds and passes its automated tests on GitHub's Windows runners, including a real server transcribing a synthetic clip — but a manual acceptance pass on real PCs (typing into Notepad, Word and browsers, the logon service, phone pairing) is still pending, and nothing is code-signed yet. Clean-up and Notes structuring run on the CPU and can be slow without a GPU; dictation works without them. If you hit a snag, the full Windows guide in the repository has a troubleshooting table and that acceptance checklist.

You need uv and Git for the server, and later Rust (MSVC toolchain), Node 22+ and WebView2 (built into Windows 11) for the desktop app.

Install the server

  1. Get the code and the environment 
    git clone https://github.com/araa47/chirp.git
cd chirp\server
uv sync --locked --extra onnx
  2. Download the speech model 
    uv run chirp-server model fetch --engine onnx

    About 650 MB, a pinned revision. Starting the server never downloads anything by itself.

  3. Choose the ONNX engine

    Put engine = "onnx" in %APPDATA%\Chirp\server.toml so both the foreground server and the background task use it.

  4. Try it, then check it 
    uv run chirp-server
uv run chirp-server doctor

    Ctrl+C stops the foreground server. doctor reports the ONNX Runtime providers, the model, the token's access list, the port and the service, one OK/WARN/FAIL line per check.

Configuration, the pairing token and device list live in %APPDATA%\Chirp, readable only by your user account; models and server state live in %LOCALAPPDATA%\Chirp, which never roams or syncs. Windows Firewall needs no rule, because the server binds to loopback only.

Keep it running

uv run chirp-server service install

This registers a per-user Task Scheduler task, Chirp Server — no administrator rights. It starts pythonw.exe (no console window) when you log on, runs only while you're logged on, restarts after a failure, and never stops on battery. You'll find it in Task Scheduler › Task Scheduler Library. Undo it with uv run chirp-server service uninstall. Flags placed before service (like --port) are kept in the task.

Install the desktop app

The desktop app is the same Tauri client Linux uses: a tray icon, a live HUD, typed or pasted text insertion and a local Notes library. Build it from the same clone:

cd chirp\desktop
npm ci
npm run build -- --bundles nsis

The installer is per-user. It's unsigned, so SmartScreen shows Windows protected your PC: choose More info › Run anyway. Open Chirp from the tray and pair it to http://127.0.0.1:7821 (or a pairing link from uv run chirp-server pair). The token is stored in Windows Credential Manager, never in a settings file.

Dictate

  1. Click into any text field

    Notepad, Word, a browser — anywhere you can type.

  2. Hold Right Alt and talk

    Release to insert. On layouts where Right Alt is AltGr (German, French, Polish and many others), Chirp’s default is Right Ctrl instead, so AltGr keeps typing @, € and friends. It picks the default from your layout the first time it creates its settings; Connection & shortcuts → Dictation key shows it, changes it and offers tap-to-toggle.

  3. Release, and it's typed

    Text is typed with SendInput. Long dictations (over 2000 characters) are pasted instead, and your previous clipboard text is restored; Chirp's clipboard writes stay out of clipboard history and cloud clipboard. Pressing any other key while holding cancels; key combinations never start dictation.

Apps running as administrator.

Windows blocks synthetic input to elevated apps. Chirp notices, leaves the text on the clipboard, and tells you to press Ctrl+V.

Notes

Open Notes from the tray or window. Record turns a long conversation into an editable Markdown document next to the transcript; completed 45-second segments save continuously, search covers titles, bodies and transcripts, deleted notes wait 30 days in Recently Deleted, and Export Markdown writes a separate file. Notes are kept only on this PC, under %LOCALAPPDATA%\chirp-desktop\notes, written only after Windows confirms an owner-only access list. Desktop Notes store text, never audio.

Structure new segments is opt-in and needs a clean-up model on the server. Without one — or with it off — Notes still keep the plain transcript.

Pair a phone

Phones reach a Windows server exactly like a Mac: over your own tailnet, never the public internet. Install Tailscale on the PC and the phone, then publish the loopback server to your tailnet only (never Funnel):

tailscale serve --bg --set-path /chirp http://127.0.0.1:7821
uv run chirp-server pair --name "My phone" --url https://<your-pc>.<tailnet>.ts.net/chirp

Scan the QR code with Chirp for Android or iPhone. The pairing link is a secret: don't paste it into chat or logs. Revoke a phone any time with uv run chirp-server devices revoke "My phone".

If something's off

  • doctor FAILs the onnx check: rerun uv sync --locked --extra onnx, then uv run chirp-server model fetch --engine onnx.
  • Service installed but not running: run uv run chirp-server in the foreground to see the startup error, then uv run chirp-server setup restart.
  • Nothing is typed: the target app may run as administrator (see above), or another tool holds a keyboard hook. Try Notepad first.
  • Releasing Right Alt opens a menu: choose Right Ctrl in Settings and report your keyboard layout.
  • Phone can't connect: tailscale serve status should show /chirp proxying to http://127.0.0.1:7821.

Every setting and path is documented in the repository's Windows guide and the desktop README.
