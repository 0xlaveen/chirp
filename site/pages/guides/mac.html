Set up Chirp on your Mac

Install Chirp from source, download a speech model, grant two permissions and dictate into any app. About 15 minutes, most of it waiting for downloads.

Needs: Apple Silicon (M1 or newer), macOS 15+Uses: Terminal, once

Before you start

Chirp runs the speech model on your Mac's Apple Silicon, so an Intel Mac won't work. You need two free developer tools. Open Terminal (press ⌘Space, type “Terminal”) and run:

xcode-select --install

That installs Apple's Command Line Tools (a dialog asks you to confirm). Then install uv, the Python tool Chirp's server uses:

curl -LsSf https://astral.sh/uv/install.sh | sh
No full Xcode needed.

The Mac app is built with the Command Line Tools alone. You don't need Tailscale for the Mac on its own — only later, if you add a phone.

Install

  1. Get the code

    In Terminal, download Chirp and step into its folder:

    git clone https://github.com/araa47/chirp.git
cd chirp
  2. Run the installer 
    ./scripts/install-mac.sh

    It installs the speech server in your Application Support folder, builds and signs Chirp.app, copies it to your Applications folder in your home folder, and opens the model picker. macOS may ask you to approve the local signing identity — allow it, so the permissions you grant survive future updates.

This is a source install.

There is no notarized download yet; the installer builds Chirp on your Mac from the code you just cloned.

Choose a model

The Models on this Mac window opens by itself. You can find it again any time under Settings → Advanced → Manage Local Models…

  1. Download a speech model

    Parakeet v2 is the English default. Pick v3 if you dictate in other languages. Downloads show progress and can be paused.

  2. Optionally, a clean-up model

    A small local language model can tidy your text afterwards. Qwen3 4B scored best in Chirp's tests; smaller ones are faster but miss more. Click Use Model to check it loads. You can skip this and add it later.

  3. Start the server

    Click Start Local Server. (After changing a model later, use Apply & Restart Server — downloading alone never swaps the running model.)

Grant two permissions

The Set Up Chirp window walks you through it, with its steps listed on the left: Welcome, Microphone, Accessibility, Speech server and Try it. Each step turns green the moment you grant access in System Settings → Privacy & Security. The last step tries a dictation, and Open Notes takes you to the notes library.

  • Microphone — so Chirp can hear you. The mic is only open while you dictate.
  • Accessibility — so Chirp can type into the app you're using. Without it, Chirp copies the text and you press ⌘V yourself.

Chirp does not need Input Monitoring. If the hotkey doesn't respond right after granting Accessibility, quit and reopen Chirp from the menu bar.

Dictate

  1. Click into any text field

    Notes, Mail, Slack, a browser — anywhere you can type.

  2. Press ⌃⌥Space and talk

    That's Control + Option + Space. A small panel appears at the bottom of the screen with rippling rings and what Chirp hears.

  3. Pause, and it's typed

    Chirp stops after about two seconds of quiet (or press the hotkey again). Esc cancels and nothing is inserted.

Prefer holding a key? In Settings → Dictation switch the mode to Hold to talk. The same page sets the shortcut: pick one such as ⌥ on its own, or record your own.

Turn on clean-up (optional)

If you downloaded a clean-up model, open Clean-up in the menu-bar menu and tick Clean up Text. Chirp then removes fillers and stutters and fixes punctuation before inserting, using the model on your Mac.

  • Styles change the tone: chat, email, code and notes. Chirp picks one by app — Mail gets email, Terminal gets code — and you can edit the list in Settings → Clean-up.
  • Use raw: changed your mind? For five seconds after a cleaned dictation, ⌃⌥Z puts back exactly what you said.

Next: press ⌃⌥N to start a note. See Take notes.

If something's off

  • “Copied — press ⌘V” instead of typing: Accessibility isn't granted yet (or the app only accepts pasting). Grant it and reopen Chirp.
  • “Server unreachable” in the menu: open Settings → Advanced and click Copy Doctor Command, then paste it into Terminal for a check-up.
  • “No microphone signal”: check the Microphone row in the menu. A Mac mini has no built-in mic.
  • A badge on General in Settings: a permission is missing. The page has a Fix… button for it.
  • Nothing in a password field: on purpose — Chirp never types into secure fields.

Every setting is explained in the Mac README.
