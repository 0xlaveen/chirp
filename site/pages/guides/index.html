Get started with Chirp

Start with the machine that runs the speech model — a Mac, a Windows PC or a Linux box. Then add a phone, or start taking notes. Every guide today builds from source.

Packaged apps coming soon

There’s no Chirp download yet. Apps for macOS, Linux, Windows, Android and iOS are on the way. New here? Read Get Chirp first, or point a coding agent at the repo — that’s the quickest path today.
